## Rebuild

The editable source is `scripts/build-resume.py`. It reads canonical business/project/award exports through Node's TypeScript stripping support, generates the public PDF with ReportLab, and renders both pages with Poppler before encoding WebP previews with Pillow. There is no separate permanent resume JSON file to synchronize. The concise editorial summary/skills live in the generator; the display name, legal business name, project/contact/recognition facts and supplied prize amounts, service titles, totals, and portrait path come from site data. `business.resumeHref` supplies the generated PDF path, and `business.resumePreview` supplies each page image path and expected intrinsic dimensions. The generator requires its rendered pages to match those dimensions before publishing.

Use the project's supported Node version, Python with `reportlab`, `Pillow`, and `pypdf`, and Poppler's `pdftoppm`:

```sh
python3 scripts/build-resume.py
```

If non-default tools are required, set `RESUME_NODE` and `RESUME_PDFTOPPM` to their verified executable paths. Bundled Poppler can also require `FONTCONFIG_FILE` pointing to its supplied font configuration. The generator stages the PDF and both previews under ignored `.local`, requires exactly two PDF pages and valid preview images, and publishes assets through atomic file replacements only after rendering succeeds. A rendering failure leaves the published PDF and previews unchanged; temporary files are removed automatically.

Preview pages are 1200 pixels wide, preserve the A4 page ratio, and use WebP quality 88. The PDF uses invariant ReportLab metadata; repeated builds with the same canonical data, authoring dependencies, and font configuration produce identical assets. ReportLab, Pillow, pypdf, Node-based extraction, and Poppler are authoring dependencies only. Deployment serves the committed PDF and images without running Python or rendering a document at request time.

Before publishing a regenerated set, inspect both preview images for spacing, text, the photograph, page numbers, and legibility. Verify the PDF's contact/project link targets, display/legal names, supplied prize amounts, and that all canonical award titles/events and all three selected projects remain present. The generator fails if content exceeds its page bounds rather than shrinking text to an unreadable size. This source record and local artifact do not imply that a website update has been deployed.
